موتور مستقل خرید و فروش - نسخه اولیه

نصب:
python -m pip install -r requirements.txt

ورودی CSV باید نمونه‌های ۵ ثانیه‌ای داشته باشد و ستون‌های زیر را دقیقاً شامل شود:
timestamp,last_price,lower_limit,upper_limit,real_buy_count,real_sell_count,
real_buy_value,real_sell_value,cumulative_volume,
ask1_volume..ask5_volume,bid1_volume..bid5_volume

هر ردیف باید timestamp قابل‌خواندن داشته باشد. حجم و ارزش در تمام ردیف‌ها باید واحد یکسان داشته باشند.
کد در این نسخه هر ۶ ردیف را یک نمونه ۳۰ ثانیه‌ای فرض می‌کند.

اجرا:
python run_dual_engine.py --input data\دابور\snapshots.csv
python run_dual_engine.py --input data\دابور\snapshots.csv --output data\دابور\گزارش.xlsx

نکات اعتبارسنجی:
۱) اگر ارزش/تعداد حقیقی در منبع تجمعی است، قبل از ورود باید اختلاف دو نمونه متوالی گرفته شود.
۲) داده‌های client type در این نسخه به‌صورت مقادیر بازه‌ای فرض شده‌اند؛ معنای واقعی ستون API باید بررسی شود.
۳) جذب عرضه فقط تخمین مبتنی بر کاهش حجم پنج ردیف عرضه و حجم معاملات است؛ لغو سفارش را نمی‌توان از snapshot ساده جدا کرد.
۴) نرمال‌سازی تطبیقی به تاریخچه قبلی همان نماد نیاز دارد. حداقل ۳۰ مشاهده برای امتیازدهی هر شاخص لازم است. پنجره مرجع حداکثر ۸۴۰۰ نمونه ۳۰ثانیه‌ای قبلی است (تقریباً معادل ۲۰ جلسه ۳.۵ ساعته، در صورت داشتن داده کامل).
۵) فایل باید تاریخچه چند روز را در برگیرد. اگر فقط داده امروز باشد، ابتدای روز در وضعیت گرم‌شدن می‌ماند.
۶) اتصال مستقیم به API تابلو هنوز در این نسخه پیاده‌سازی/اعتبارسنجی نشده است. ابتدا قالب CSV و صحت داده‌ها باید با نمونه واقعی بررسی شود.
۷) امتیازها شاخص شدت نسبی‌اند و احتمال رشد/ریزش نیستند.
